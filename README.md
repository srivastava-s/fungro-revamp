# Funngro Website Revamp

🚀 **Live Demo:** [https://fungro-revamp-blue.vercel.app/](https://fungro-revamp-blue.vercel.app/)

A modern, responsive, and SEO-optimized redesign of the Funngro Teen Earning Platform. This project revamps the user experience for both **Teen Freelancers** (B2C) and **Companies Hiring Talent** (B2B).

## 🌟 Key Features

### For Teens (`/index.html`)
- **Earn While You Learn**: Clear value proposition for students.
- **Outcome Focused**: Showcases skills, real money earnings, and success stories.
- **Trust Signals**: Safety promise, parent verification, and ratings.

### For Companies (`/company.html`)
- **Hire Gen-Z Talent**: Dedicated B2B landing page.
- **ROI Centric**: Focus on cost-efficiency, speed, and digital-native skills.
- **Compliance**: Badge system for legal/safety compliance (GST, Minor Labor Laws).

## 🛠️ Technology Stack
- **Framework**: [Vite](https://vitejs.dev/) (High-performance build tool)
- **Core**: Semantic HTML5, Vanilla JavaScript (ES6+), CSS3 Variables.
- **Styling**: Mobile-first responsive grid system.
- **Icons**: FontAwesome 6.

## 📈 SEO & Accessibility
This project includes a comprehensive SEO overhaul:
- **Semantic HTML**: Proper use of `<main>`, `<article>`, `<nav>` for accessibility.
- **Schema Markup**: `Organization` and `FAQPage` JSON-LD for rich snippets.
- **Meta Optimization**: Keyword-rich titles and descriptions for high-intent queries.
- **Audit Report**: Includes a downloadable [SEO Audit Report](/seo-report.html).

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/srivastava-s/fungro-revamp.git

# Navigate to project directory
cd fungro-revamp

# Install dependencies
npm install

# Start development server
npm run dev
```
